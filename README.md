# Raihan Mahmud — Portfolio

Personal site for a Computer Science undergraduate targeting software engineering and machine learning roles.

**Claim:** I build practical software and machine-learning systems to solve real problems.

## Stack

Vite · React · Tailwind CSS · Framer Motion

## Local

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
npm run preview
```

## Deploy

Configured for Vercel (`vercel.json`, Vite output in `dist`). Connect the repo in Vercel and deploy; no extra framework settings are required.

## Manual follow-ups

- Place the CV at `public/cv.pdf`, then uncomment the View CV link in `src/components/Hero.jsx`.
- When FlyRank provides an official badge image and verification URL, insert them in `src/components/Footer.jsx`.
